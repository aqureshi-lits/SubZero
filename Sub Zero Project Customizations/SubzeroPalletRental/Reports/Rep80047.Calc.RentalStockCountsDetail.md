# Rep80047 - Calc.RentalStockCountsDetail

## Overview
Report ID **80047** titled **"Calculate Rental Stock Counts Detail"** is the main report used for pallet rental calculation. It calculates warehouse rental stock counts detail including inbound/outbound quantities, pallet occupancy, balance, and chargeable pallets per customer and storage condition.

- **ProcessingOnly**: true
- **UseRequestPage**: true
- **Caption**: 'Calculate Rental Stock Counts Detail'

## Request Page Fields
| Field | Caption | Application Area |
|-------|---------|------------------|
| StartDate | Start Date | All |
| EndDate | End Date | All |

## Dataset Structure
The report processes data through a looping structure based on `DaysInPeriod`:

1. **DaysLoop** (Integer) - Sorted ascending, iterates from 0 to DaysInPeriod
   - OnPreDataItem: Sets range `Number` from 0 to `DaysInPeriod`
   - OnAfterGetRecord: Calculates `AsOnDate := StartDate + Number`

2. **Customer** - Filtered by customer No.
   - RequestFilterFields: "No."

3. **Storage Condition** - Filtered where "Use for Warehouse Rents" = true
   - RequestFilterFields: Code
   - OnAfterGetRecord: Calls `ProcessCustomerStorageCondition`

## Triggers

### OnInitReport
- Sets `StartDate` from `DailyRentalStock.FindLast()` (Posting Date + 1)
- Sets `EndDate` to `WorkDate() - 1`

### OnPreReport
- Calls `ValidateRequestDates()`
- Clears all accumulator caches (RunningItemQuantity, MonthlyFeeCharged, FixedChargeCharged, ChargedReceipts)

### OnPostReport
- Displays message: 'Warehouse rental lines calculation completed.'

## Local Procedures

### Validation
- **ValidateRequestDates**: Validates StartDate/EndDate are set, StartDate <= EndDate, both before WorkDate()

### Customer Processing
- **ProcessCustomerStorageCondition**: For each storage condition, resets totals, gets storage rate, filters items by customer and storage condition with "Purchase Exist", accumulates item movements, then inserts customer line

- **AccumulateItem**: Core calculation procedure that:
  - Gets `QtyPerPallet` from item, errors if 0
  - Gets opening quantity via `GetOpeningQuantity`
  - Calculates daily movements (inbound/outbound) via `CalculateDailyMovements`
  - Computes `ItemOccupancy` and `ItemBalance` (ensuring balance >= 0)
  - Accumulates UOM and pallet totals
  - Retrieves latest inbound ILE terms via `WMSBillingManagement.GetLatestInboundTerms`
  - Applies minimum storage day rules if applicable
  - Updates `MinRuleChargeablePallets`
  - Stores running item quantity

- **InsertCustomerLine**: Inserts the final daily rental stock detail record
  - Rounds pallet quantities once at customer level
  - Sets posting date, customer code/name, storage condition, per day rate
  - Populates all UOM and pallet columns
  - Handles GRN/GDN number joining
  - Determines WMS Billing Type (fallback to "Fixed Location" or "Normal")
  - Calculates chargeable pallets based on billing type
  - Applies monthly charges (management fee + fixed monthly charge)
  - Calls `CalculateReceiptCharges()` for GRN-level charges
  - Populates OverTime, Plug In, DM Inspection, Handling Charges
  - Computes Total Charges
  - Inserts record and marks monthly charges as applied

### Receipt (GRN) Charges - Calculated Once Per GRN
- **AddReceiptPallets**: Adds pallets to ReceiptPallets dictionary (avoids duplicates)

- **CalculateReceiptCharges**: For each unique receipt number (not yet charged):
  - Reads the first Item Ledger Entry (ILE) of the GRN
  - Extracts OverTime, PlugIn, DMInspection from ILE
  - Gets container charges via `GetContainerCharges`
  - Calculates Handling based on container type:
    - "Loose Pallet": Rate * Pallets
    - "Internal Transfer": Fixed + per-pallet charge (`GetInternalTransferCharge`)
    - Else: Flat rate
  - Marks receipt as charged

- **GetInternalTransferCharge**: Tiered pricing:
  - <= 0 pallets: 0
  - 1-5 pallets: 50 flat
  - >= 6 pallets: Pallets * 10

### Item Ledger Helpers
- **GetOpeningQuantity**: Cached opening quantity from item ledger entries posted before StartDate

- **CalculateDailyMovements**: For a specific AsOnDate, calculates:
  - **QtyIn**: Inbound (Purchase + Positive Adjmt) quantities
  - **QtyOut**: Outbound (Sale + Negative Adjmt) quantities
  - Tracks distinct GRN (GRN Nos) and GDN (GDN Nos) numbers
  - Accumulates receipt pallets

### Rates & Monthly Charges
- **GetStorageRate**: Looks up "Rent Pallet/Day" from Storage Condition_Customer record

- **GetContainerCharges**: Looks up container charges from Charges table by container type and customer

- **ApplyMonthlyCharges**: 
  - Management Fee: (Customer WMS Management Fee / 30) * GetDaysInMonth(AsOnDate)
  - Fixed Monthly Charge: Customer WMS Fixed Monthly Charge (if billing type = "Fixed Location" and TotalOccupancyPallets >= 1)

- **IsMonthlyChargeApplied**: Checks if charges already applied for current month key (CustomerNo + Year+Month format)

- **MarkMonthlyChargesApplied**: Marks monthly fees/fixed charges as applied for the month

- **GetMonthKey**: Returns `CustomerNo + '|' + Format(AsOnDate, 0, '<Year4><Month,2>')`

- **GetDaysInMonth**: Returns days in month using Date2DMY calculation

### Reset & Utilities
- **ResetTotals**: Clears all accumulator variables and lists

- **Reset Monthly Tracking**: Manages monthly charge cache state

### GRN/GDN Number Extraction
- **GetPurchaseOrderNo**: Extracts Vendor Shipment No. from Purchase Receipt ILE
- **GetSalesOrderNo**: Extracts External Document No. from Sales Shipment ILE
- **AddDistinct**: Adds document number to list if not already present
- **JoinList**: Joins list of document numbers into comma-separated text

## Calculation Flow

1. **Initialization**: OnInitReport sets date range from Daily Rental Stock record

2. **Daily Loop**: For each day in the period:
   - Process each customer
   - For each storage condition of that customer:
     - Filter inventory items with "Purchase Exist" = true
     - For each item:
       - Get opening quantity
       - Calculate inbound/outbound movements for the day
       - Compute occupancy and balance pallets
       - Retrieve storage terms and apply minimum storage day rules
       - Accumulate totals

3. **Insert Customer Line**: After processing all items for a storage condition:
   - Round all pallet quantities
   - Determine billing type and chargeable pallets
   - Apply monthly charges
   - Calculate GRN-level charges (once per GRN)
   - Insert detail record

4. **Report Completion**: OnPostReport confirms completion

## Key Calculations

- **Goods In (Round-Pallet)**: `Round(GoodsIn_Actual_Pallet, 1, '>')`
- **Goods Out (Round-Pallet)**: `Round(GoodsOut_Actual_Pallet, 1, '<')`
- **Total Occupancy Pallets**: `Round(TotalOccupancyPallets, 1, '>')`
- **Balance Pallets**: `Round(BalancePallets, 1, '>')`
- **Minimum Pallets Rule**: If inbound ILE exists and "WMS Minimum Storage Days" > 0, and AsOnDate is within the minimum period, use `InboundILE.Quantity / QtyPerPallet` as minimum chargeable
- **Chargeable Pallets**:
  - "Fixed Location" billing: `TotalOccupancyPallets - WMS Allocated Pallets` (minimum 0)
  - "Normal" billing: `MinRuleChargeablePallets`
- **Total Charges**: `Management Fee + Fixed Monthly Charge + (PerDayRate * ChargeablePallets) + OverTime + PlugIn + DMInspection + Handling`

## Output
The report inserts records into "Daily Rental Stock Detail" containing:
- Posting Date, Customer Code/Name, Storage Condition
- Per Day Rate
- Goods In/Out (UOM and Round/Actual Pallets)
- Same Day In-Out quantities
- WMS Total/Balance/Chargeable Pallets
- GRN and GDN numbers
- WMS Billing Type
- Management Fee, Fixed Monthly Charge
- Over Time, Plug In, DM Inspection, Handling Charges
- Total Charges
